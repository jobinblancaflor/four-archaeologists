# The Adventure of Four Archaeologists

An animated cartoon series about four friends — **Johan** (the leader), **Thor**, **Julius** and **Asher** — who travel the world searching for four ancient medallions.

**▶ Watch it here:** https://jobinblancaflor.github.io/four-archaeologists/

## Season 1
1. The Secret of the Golden Medallion
2. The Door of Four Tools
3. The Island of Whispers
4. The Desert of Echoes
5. The Frozen Peak (Season 1 Finale)

## Season 2
6. The Sunken City
7. The Pearl of Tides

## About
- Characters are based on an original hand drawing.
- Animation is hand-coded SVG + JavaScript in a single `index.html` — no build step.
- Voice-over generated with [Kokoro TTS](https://github.com/hexgrad/kokoro) (Apache 2.0); clips are in `vo/`.
